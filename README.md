# 일정 관리 달력 웹 앱

## 사용 방법

1. `calendar-app/index.html`을 브라우저에서 열어주세요.
2. 달력에서 날짜를 클릭하면 오른쪽에서 일정을 추가할 수 있습니다.
3. 입력한 일정은 브라우저 `localStorage`에 저장되어 동일한 컴퓨터에서 다시 열어도 유지됩니다.
4. "삭제" 버튼을 누르면 선택된 날짜의 모든 일정이 삭제됩니다.

## 파일 구성

- `index.html` - 앱의 메인 페이지
- `styles.css` - 스타일 정리
- `script.js` - 달력 렌더링 및 일정 저장 로직
